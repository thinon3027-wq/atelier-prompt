6 Réglages du jeu ou de l'application
Tuto : comment je récupère les résultats de mes élèves ?

Le principe. Le jeu est un seul fichier HTML. L'élève joue, puis le jeu lui donne son résultat. Vous ouvrez le même fichier sur votre propre PC, cliquez sur l'espace professeur et importez les résultats : tout s'affiche dans le tableau de bord. Aucun serveur, aucun compte.

1. Hors ligne, PC différents (recommandé) — marche sans Internet et quel que soit l'ordinateur de l'élève.

  1. Déposez le fichier HTML sur l'ENT, une clé USB ou le dossier partagé de la salle.
  2. En fin de partie, l'élève clique sur Copier mon code ou Télécharger mon fichier résultat.
  3. Il vous le transmet : message ENT, devoir à rendre, mail, ou fichier copié sur votre clé USB.
  4. Sur votre PC, ouvrez le jeu, cliquez sur l'espace professeur, saisissez le code à 4 chiffres.
  5. Collez les codes (plusieurs à la suite) ou glissez les fichiers résultat : le tableau se remplit et reste mémorisé sur votre PC.
  6. Exportez en CSV pour Pronote ou un tableur, ou sauvegardez la session complète.

2. Même appareil — pour des tablettes ou des postes que vous consultez vous-même : les résultats restent dans le navigateur du poste. Pour regrouper plusieurs postes, exportez le fichier de chaque poste puis importez-les sur le vôtre.

3. Google Sheets — les résultats arrivent seuls dans un tableur, mais il faut Internet et un compte Google. Si la connexion coupe, le jeu garde le résultat et propose le code de secours.

Le prompt demande à l'IA d'intégrer ce tuto dans l'espace professeur du jeu et une consigne courte pour les élèves.
